# Mehari Woldegebrel | HTML Portfolio

A lightweight, single-page personal portfolio built entirely with semantic HTML5 to showcase my work as a Frontend Developer.
##  Quick Start
Double-click `index.html` to open it in any web browser. No installation or build process is required.

## Features
* **Semantic HTML5:** Built using standard structural tags (`<header>`, `<main>`, `<section>`).
* **Navigation:** In-page anchor links connecting the Home, About, and Contact sections.
* **Contact Form:** Fully structured form utilizing text, email, dropdown, and textarea inputs.
